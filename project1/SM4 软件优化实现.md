## 概述
本文档描述了 SM4 分组密码算法的优化实现，包括基础实现和查表法优化实现。SM4 是中国国家密码管理局发布的分组密码标准。本实现提供了两种加密方法：基础方法和查表法优化方法，并包含性能对比分析。

## 算法原理

### SM4 基本结构
SM4 是 128 位分组密码，采用 32 轮非线性迭代结构（Feistel 网络）：
- 分组长度：128 位
- 密钥长度：128 位
- 轮数：32 轮

### 轮函数
轮函数是 SM4 的核心，定义为：
```
F(X0, X1, X2, X3, rk) = X0 ⊕ T(X1 ⊕ X2 ⊕ X3 ⊕ rk)
```
其中：
- `X0, X1, X2, X3` 是 32 位输入字
- `rk` 是轮密钥
- `T` 是合成置换

### T 变换
T 变换由非线性变换 τ 和线性变换 L 复合而成：
```
T(.) = L(τ(.))
```

#### 非线性变换 τ
τ 由 4 个并行的 S 盒构成：
```
B = τ(Z) = (Sbox(Z0), Sbox(Z1), Sbox(Z2), Sbox(Z3))
```

####  线性变换 L
L 变换定义为：
```
L(B) = B ⊕ (B <<< 2) ⊕ (B <<< 10) ⊕ (B <<< 18) ⊕ (B <<< 24)
```

## 优化方法：查表法

### 优化原理
T 变换是轮函数中最耗时的部分，我们通过预计算来加速这一过程。将 T 变换分解为 4 个查表操作：

1. 将 32 位输入 Z 拆分为 4 个字节：`Z = (Z0, Z1, Z2, Z3)`
2. T 变换可表示为：
   ```
   T(Z) = L(τ(Z)) 
         = L( (Sbox(Z0), Sbox(Z1), Sbox(Z2), Sbox(Z3)) )
         = [ (Sbox(Z0)<<24) | (Sbox(Z1)<<16) | (Sbox(Z2)<<8) | Sbox(Z3) ] 
           ⊕ [ (Sbox(Z0)<<24) | (Sbox(Z1)<<16) | (Sbox(Z2)<<8) | Sbox(Z3) ] <<< 2
           ⊕ ...  // 其他移位
   ```
3. 根据线性性质，L 变换可拆分为 4 个独立部分：
   ```
   T(Z) = [L(Sbox(Z0) << 24)] ⊕ 
          [L(Sbox(Z1) << 16)] ⊕ 
          [L(Sbox(Z2) << 8)]  ⊕ 
          [L(Sbox(Z3))]
   ```

### 预计算表
我们预先计算 4 个表（每个表 256 个 32 位字）：
- `T0[i] = L( (uint32_t) Sbox[i] << 24 )`
- `T1[i] = L( (uint32_t) Sbox[i] << 16 )`
- `T2[i] = L( (uint32_t) Sbox[i] << 8 )`
- `T3[i] = L( (uint32_t) Sbox[i] )`

### 优化后的 T 变换
使用预计算表后，T 变换简化为：
```
T(Z) = T0[Z0] ⊕ T1[Z1] ⊕ T2[Z2] ⊕ T3[Z3]
```

### 优势
1. 减少计算量：
   - 原始：4 次 S 盒查表 + 4 次移位 + 12 次异或
   - 优化后：4 次表查找 + 3 次异或
   
   

## 性能优化

### 测试环境
- 硬件环境：处理器12th Gen Intel(R) Core(TM) i7-1260P   @ 2.10 GHz
- 软件环境：visual studio 2022

### 结果
| 实现方式 | 时间 (秒) | 吞吐量 (MB/s) |      |
| -------- | --------- | ------------- | ---- |
| 基础方法 | 0.5430    | 29.47         |      |
| 查表法   | 0.2350    | 68.09         |      |

### 结论
查表法通过预计算 T 变换，显著减少了轮函数的计算开销，在测试中实现了 2.31 倍的性能提升。这种优化适合高性能应用场景，如服务器端加密和大数据加密处理。
