# SM3 软件实现与优化核心思想

## 基础实现
1. **消息填充**：
   - 添加 0x80 标志位
   - 填充 0 至长度 ≡ 56 mod 64
   - 最后 8 字节写入消息位长度（大端序）

2. **消息扩展**：
   - 将 512bit 块扩展为 68 个 W 字
   - 核心公式：
     ```
     W[i] = P1(W[i-16]⊕W[i-9]⊕ROTL(W[i-3],15))
            ⊕ ROTL(W[i-13],7) ⊕ W[i-6]
     ```
   - 生成 64 个 W' 字：W'[i] = W[i]⊕W[i+4]

3. **压缩函数**：
   - 8 个状态寄存器（A-H）迭代 64 轮
   - 每轮核心操作：
     ```
     SS1 = ROTL(ROTL(A,12)+E+ROTL(Tj,j%32), 7)
     TT1 = FF_j(A,B,C) + D + (SS1⊕ROTL(A,12)) + W'[j]
     TT2 = GG_j(E,F,G) + H + SS1 + W[j]
     ```
   - 状态更新：D=C, C=ROTL(B,9), B=A, A=TT1, H=G, G=ROTL(F,19), F=E, E=P0(TT2)

## AVX2 优化核心
1. **并行架构**：
   - 同时处理 8 个独立消息块
   - 8 个向量寄存器存储 8 个独立状态（每个寄存器包含 8 个通道的状态值）

2. **数据重组**：
   ```plaintext
   原始数据布局：
     [块0字0][块0字1]...[块0字15]
     [块1字0][块1字1]...
      ...
     
   转置后布局（AVX2）：
     向量0: [块0字0][块1字0]...[块7字0]
     向量1: [块0字1][块1字1]...[块7字1]
      ...
   ```

3. **向量化关键操作**：
   - **置换函数**：使用 `_mm256_xor_si256` + `mm256_rotl_epi32` 实现 P0/P1
   - **布尔函数**：
     - FF0/GG0：向量异或 `_mm256_xor_si256`
     - FF1：向量与/或组合 `_mm256_and_si256` + `_mm256_or_si256`
     - GG1：`_mm256_andnot_si256` 实现条件取反
   - **轮函数**：
     - 常量广播：`_mm256_set1_epi32(Tj)`
     - 并行移位：`mm256_rotl_epi32` 自定义循环移位

4. **尾块处理策略**：
   - 提取首个通道状态单独处理
   - 基础算法处理尾块
   - 仅更新首个通道状态

## 关键优化技术
1. **指令级优化**：
   - 预计算轮常数（减少寄存器压力）
   - 循环展开（4-8 轮/次减少分支）
   - 常量广播复用

2. **内存优化**：
   - 32 字节对齐内存分配
   - 顺序访问模式（减少 cache miss）
   - 局部变量对齐声明（`ALIGN32`）

3. **分支优化**：
   - 拆分 0-15 轮和 16-63 轮循环
   - 消除轮次条件判断
