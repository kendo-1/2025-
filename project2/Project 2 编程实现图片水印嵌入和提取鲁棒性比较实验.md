# Project 2: 编程实现图片水印嵌入和提取鲁棒性比较实验

## 实验目的
Project 2: 编程实现图片水印嵌入和提取（可依托开源项目二次开发），并进行鲁棒性测试，包括不限于翻转、平移、截取、调对比度等，采用两种主流数字水印算法（LSB和DCT）在不同图像处理攻击下的鲁棒性表现，评估它们在现实应用场景中的可靠性。

###  实验方法
- **测试算法**：
  - LSB（最低有效位）算法：直接在像素最低位嵌入水印
  - DCT（离散余弦变换）算法：在频域中频系数嵌入水印
- **测试水印**：文本水印"kendo-202200460165"（16字符）
- **测试图像**：标准测试图像"host.jpg"
- **攻击类型**：共测试17种图像处理操作，包括：
  - 几何变换：旋转、翻转、平移、裁剪
  - 颜色调整：对比度增强/减弱、亮度增加/减少
  - 压缩处理：JPEG压缩（不同质量）
  - 空间变换：模糊、缩放

## 实验结果分析

**LSB算法表现**：
- 优势：
  - 对无损操作（翻转、平移）鲁棒性极佳（BER=0）
  - 实现简单，计算效率高
- 劣势：
  - 对任何像素值修改极其敏感
  - JPEG压缩（质量30）导致BER高达0.8以上
  - 对比度/亮度调整造成BER>0.4
  - 缩放操作导致水印完全破坏

**DCT算法表现**：
- 优势：
  - 对JPEG压缩鲁棒性强（质量30时BER<0.1）
  - 抵抗颜色调整能力出色（对比度/亮度变化BER<0.2）
  - 适度抵抗模糊操作（BER≈0.15）
- 劣势：
  - 几何攻击仍是主要弱点
  - 大角度旋转（30°）导致BER>0.4
  - 大幅裁剪（30%）破坏水印结构
